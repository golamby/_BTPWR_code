## 当前原型的实质边界

标准组件：Ed25519、X25519/HKDF-SHA256/AES-GCM、mTLS、2048位 Paillier、实际 PyEVM 合约执行。

匿名注册表与强制后继由诚实服务器检查；链上记录整批根，不单独证明每个后继的数值正确性。合约现有的是预算承诺与轮次状态机，不是实际货币兑付。若要求真实资产支付，还需单独实现托管和提款，并测量其额外开销，不能把摘要提交称为资金到账。

当前测试是同一物理主机上的分进程服务和真实 TCP/TLS，不能称为独立运营实体的物理隔离或广域共识网络。100份客户私有状态由测试控制器驱动；真实身份表仅属于注册端，真值和评价标签仅属于实验审计端。控制器不是产品协议中的额外计算参与方。
